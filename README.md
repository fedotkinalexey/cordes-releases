# Cordes for Mac

Builds of the Cordes desktop app (Apple Silicon). Download the `.dmg` from the
latest release:

**https://github.com/fedotkinalexey/cordes-releases/releases/latest**

Once installed, Cordes finds new versions here by itself and offers
**Restart to update**. Nothing is installed until you press it.

The first time, macOS may say it can't check the app for malicious software,
because these builds aren't notarised by Apple. Open **System Settings →
Privacy & Security** and press **Open Anyway** next to Cordes. Updates after
that don't ask again.

This repository holds only the builds and the workflow that makes them. The
source is private.
